# Season 2 Results

Store raw machine-readable outputs here, preferably one JSON file per experiment and one optional human-readable summary beside it.

Each result should include:

- experiment id
- source commit
- model name and complete configuration
- parameter count
- dataset and split
- seed(s)
- training steps or epochs
- optimizer and learning-rate schedule
- hardware and precision
- runtime
- validation metrics
- checkpoint path, if any
- known caveats
